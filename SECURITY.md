# Security Policy

## Supported Versions

For now `recdb` uses very defensive version numbers. There's no major version yet. 
In turn there's only one supported version and this is the latest.

## Reporting a Vulnerability

To report a vulnerability head over to the [Security Advisories](https://github.com/mofosyne/recdb/security/advisories) 
page and click on "New draft security advisory".

Feel free to contact me at khuubrian@gmail.com if you have any questions or want to discuss things
beforehand.
